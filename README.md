# ZAYBALNOMA

Fayllar: `index.html` (sayt), `data.json` (hamma matn va rasm yo'llari), `images/` (rasmlar, o'zingiz yaratasiz).

## GitHub Pages
1. Repo yarating va shu fayllarni yuklang (rasmlar bo'lsa `images/` papkasi bilan).
2. Settings -> Pages -> Deploy from a branch -> `main` / root.

## Tahrirlash
1. Saytni `.../#admin` bilan oching (yoki pastdagi "admin" havolasi).
2. Oy, kartochka, matn, rasm: hammasini o'zgartiring. Rasm uchun "Rasm yo'li" ga `images/nom.jpg` yozing (fayl repoda bo'lsin).
3. "data.json olish" -> chiqqan matnni repodagi `data.json` ga qo'yib commit qiling.

Admin rejimdagi o'zgarishlar faqat sizning brauzeringizda qoralama bo'lib turadi. Saytni hamma ko'radigan qilish uchun data.json ni commit qilish kerak.
